How would you like to submit your manuscript?

Both methods produce the same published result. Choose based on how you prefer to write.

Recommended for most authors

Write in the browser

  • See your article as you write it — no markup syntax to learn
  • Upload images, video, and audio directly into the text where they appear
  • Insert footnotes with a click; they are numbered and placed automatically
  • Add citations manually or import a .bib file from your reference manager
  • Cross-reference figures and tables by name — numbering is handled for you
  • Equations supported via LaTeX input with live preview

Not suitable if your article relies heavily on LaTeX packages, custom macros, or complex tables with merged cells.

Open Editor →

Upload a LaTeX file

  • Write and edit entirely offline using tools you already know — Overleaf (browser-based, no install needed) or LaTeX Workshop for VS Code
  • Keep your manuscript in version control alongside your research notes
  • Custom LaTeX macros and packages are preserved where supported
  • Bibliography parsed directly from your .bib file
  • Full support for mathematical notation and complex equations

Requires knowledge of LaTeX. Media files must be uploaded separately and their filenames must match the macros in your .tex source exactly. See the author & template guidelines for the journal's custom macros (\ARJfigure, \ARJvideo, etc.) — the LaTeX template can be downloaded from that page.
